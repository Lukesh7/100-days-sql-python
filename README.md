## 📚 Learning Roadmap

### Phase 1: Beginner (Days 1–25)

**Focus:** SQL fundamentals and Python basics

**SQL**

* SELECT statements
* Filtering with WHERE
* Sorting with ORDER BY
* Aggregate functions
* Basic data analysis queries

**Python**

* Variables and data types
* Conditional statements
* Loops
* Functions
* Lists, tuples, sets, and dictionaries

### Phase 2: Intermediate (Days 26–50)

**Focus:** Relational databases and data manipulation

**SQL**

* INNER JOIN and LEFT JOIN
* GROUP BY and HAVING
* Subqueries
* Combining data from multiple tables

**Python**

* Pandas fundamentals
* Data filtering and grouping
* Data cleaning
* Handling missing values
* Basic data analysis

### Phase 3: Upper Intermediate (Days 51–75)

**Focus:** Advanced querying and exploratory data analysis

**SQL**

* Common Table Expressions (CTEs)
* Window functions
* Advanced analytical queries
* SQL-based business analysis

**Python**

* Exploratory Data Analysis (EDA)
* Connecting Python with SQL
* Data visualization
* Matplotlib charts
* Extracting business insights

### Phase 4: Advanced Practice (Days 76–100)

**Focus:** Business problems and portfolio development

* Advanced SQL challenges
* Query optimization fundamentals
* Business case studies
* Analytical problem-solving
* Data-driven decision-making
* Final capstone project
